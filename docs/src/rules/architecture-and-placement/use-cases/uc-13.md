# UC-13 · La command porte l’appelant

<RuleMeta />

## Signal

- Un use case qui lit l’utilisateur courant dans un état global, ou dans la requête HTTP.
- Le token, ou son contenu brut, passé au use case.
- Un consumer ou un job qui appelle un use case sans appelant.

## Pourquoi

Passé dans la command, l’appelant se voit dans la signature du use case. Il se teste sans requête HTTP, et vaut pour chaque point d’entrée : HTTP, consumer ou job (UC-06). Un état global ne se voit pas, et seul le chemin HTTP le remplit.

## Exceptions

Aucune.

## Correction

- La command porte l’appelant : un concept local, `Caller`, son identité et ses rôles, que l’adapter driving construit (SEC-02).
- Un consumer ou un job passe un appelant système, nommé.

## Voir aussi

SEC-02 tire l’appelant de l’authentification. UC-06 vérifie ses droits dans chaque use case.
